## 📖 About The Project

**IF-Shield** is not just another website blocker. It is a strict "Time Guardian" designed specifically to pull you out of the endless loop of YouTube Shorts. 

Time is a developer's most valuable asset. This Chrome Extension allows you to set a daily or session-based limit for YouTube Shorts. Once your time is up, it aggressively cuts off the feed and hits you with a harsh, reality-checking motivational quote from history's greatest leaders, thinkers, and sports legends (e.g., Mustafa Kemal Atatürk, Mehmed the Conqueror, Zeljko Obradovic, Cristiano Ronaldo).

No more "just one more video" excuses. 

## ✨ Features

*   ⏱️ **Strict Time Limits:** Set your own scrolling budget. Once it's gone, it's gone.
*   🛑 **Hard Block Mechanism:** Instantly stops the video stream and hides the Shorts UI.
*   🔥 **Legendary Motivations:** Displays a randomly selected, verified quote from a hard-working legend to kill your urge to procrastinate.
*   🌍 **Bilingual Support (i18n):** Motivation quotes are available in both English and Turkish.
*   ⚡ **Lightweight & Fast:** Built with pure JavaScript, taking zero toll on your browser's performance.

## 🚀 Installation

1. Clone the repo:
   ```sh
   git clone [https://github.com/if-ies/if-shield.git](https://github.com/if-ies/if-shield.git)
2. Open Google Chrome and go to chrome://extensions/

3. Enable "Developer mode" in the top right corner.

4. Click on "Load unpacked" and select the cloned project folder.

5. Pin the extension to your toolbar and take your time back!
